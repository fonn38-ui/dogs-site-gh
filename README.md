# Paws Haven — сайт передержки собак

Полностью готовый статический сайт. Заливается на GitHub Pages за 2 минуты.

## Что внутри

```
dogs-site-gh/
├── index.html     20 KB — главная
├── styles.css     30 KB — премиум-дизайн
├── data.js        15 KB — тексты (породы, истории, услуги, команда, FAQ)
├── script.js      18 KB — кинематика, лайтбокс, формы
└── README.md      этот файл
```

Локальные фото (`assets/breeds/`) не нужны — сайт берёт рандомные фото с `placedog.net` + Unsplash. Есть локальный fallback на всякий случай (его добавьте сами в `assets/breeds/`, если хотите).

## Как залить на GitHub Pages (вариант через web-интерфейс)

### 1. Создать репозиторий

Откройте https://github.com/new

- **Repository name**: `paws-haven` (или любое)
- **Public** ✅
- **Add a README file** — НЕ ставить, мы загрузим свой
- Нажмите **Create repository**

### 2. Загрузить файлы

На странице пустого репозитория GitHub предложит:
- **uploading an existing file** — ссылка. Нажмите.

Далее в проводнике выделите все файлы из папки `dogs-site-gh` и перетащите в окно загрузки:
- `index.html`, `styles.css`, `data.js`, `script.js`, `README.md`

После того как файлы перетащатся и появятся в списке — нажмите **Commit changes**.

### 3. Включить GitHub Pages

В репозитории → вкладка **Settings** → слева **Pages**:

- **Source**: `Deploy from a branch`
- **Branch**: `main` / `(root)` — выберите
- Нажмите **Save**

Подождите 1–2 минуты. Сайт откроется на адресе:

```
https://fonn38-ui.github.io/paws-haven/
```

(где `paws-haven` — имя вашего репозитория)

### 4. Если хотите свой домен

В том же разделе **Pages** → поле **Custom domain** → введите домен → **Save**.

GitHub создаст файл `CNAME` (мы его не добавляли) и попросит прописать A-записи у регистратора:

```
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
```

и `CNAME www → fonn38-ui.github.io.`

Подробнее — спросите у Hermes.
